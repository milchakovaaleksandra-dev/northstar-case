# NorthStar People Analytics

Portfolio case study by Aleksandra Milchakova, HR Analyst.

A four-page Power BI HR dashboard for NorthStar, a fictional IT company with 800 employees (2024–2025): headcount, turnover, compensation, absences and utilization. The case follows six steps: Ask, Prepare, Process, Analyze, Share, Act.

All data is synthetic and used for practice only.
